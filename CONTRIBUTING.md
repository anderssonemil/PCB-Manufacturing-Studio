# Contributing

Start with README, docs/architecture.md and docs/development.md. Use synthetic boards
for reproducible issues, keep changes focused and run the applicable checks. Explain
units, coordinate systems, intended retained copper and expected tool/beam footprint.

Never submit personal board designs, photos, credentials, device settings, generated
jobs or laser/CNC programs by accident. Hardware submissions are manual and explicit;
geometry tests must not send jobs to a real device. Include machine/process context
when reporting physical results, and distinguish measurements from photo estimates.

Original contributions use the repository's MIT license. Preserve third-party license
headers and pinned provenance. Discuss larger roadmap items before implementation.
