PCB Isolator · Workflow guide

PCB Manufacturing Studio · single-sided milestone 0.3.0-rc.1

A saved KiCad board becomes reviewed laser isolation paths, then drilling and profile files for the configured CNC. Reference-layer viewing does not select manufacturing layers. Current manufacturing uses B.Cu only.

Normal workflow

  1. Refill copper zones and save in KiCad. Open the saved board in the app.
  2. Select registration holes and the selected hole that defines router XY zero. Review the actual process/tool settings.
  3. Press blue Generate preview. Laser and router reviews open independently.
  4. Inspect the drawings, omitted details, toolpaths and setup instructions. Then use green Generate outputs to create final output from the reviewed file set.
  5. For direct Helix printing, use the separate Send action after reviewing. Sending queues a job; start it at the laser panel.
  6. Clean/etch, prepare PCB registration holes, register with pins and tape, then remove all pins before PCB machining. Follow the generated guide for each tool.

Files and project controls

Open KiCad board… accepts a .kicad_pcb or matching .kicad_pro. It exports a snapshot of saved contents, not unsaved editor changes. Choose output folder… selects the final destination. More options contains Open existing job and Reload latest saved KiCad board.

Open existing job reopens a previous exported snapshot. Reload latest saved KiCad board makes a fresh export from the saved source; it does not save the KiCad editor. Confirm that the source board and intended revision are correct.

Alignment and XY zero

Click a round hole or use the table. Circular internal Edge.Cuts are also candidates. Two or more distinct locations are needed for final router output. Incomplete alignment can produce a clearly labelled preview; laser-only boards can have no holes.

Undersized selections need manual preparation for the configured pin diameter. Coincident drill entries at those centers are excluded from ordinary drilling. The original KiCad geometry is not resized. Selected circular outline locations are manually prepared and excluded from profile routing. A warning identifies pin holes that would extend beyond the outer edge.

Yellow arrows show router XY zero. Without selected holes it is provisionally at the copper lower-left. Laser top-left placement is a separate coordinate system. Registration pins locate the taped board; they are removed before PCB drilling/profile, so normal travel has no pin keepouts or detours.

Laser settings and review

Configure the actual Helix IP/port, speed/power percentages, frequency and DPI. Autofocus is off, software focus offset is zero, and focus is manual. Air and exhaust remain manual. Check connection only checks reachability. Transfer progress/acknowledgement confirms queue submission, not actual machine start or completion.

Trial directional compensation uses separate X/Y paint-removal widths, adaptive maximum lanes and spacing. It is a provisional process model, not a guaranteed optical spot or minimum trace rule. Narrow-gap rescue can intentionally remove copper where the measured burn does not fit; inspect orange predicted intrusion. Tapered dead ends into solid copper are rejected rather than adding diagonal engraving spurs.

Artwork top-left, including path extents, is placed at X0/Y0 plus configured positive offsets. Negative offsets are not supported. At 600 DPI the integer grid is 0.042333 mm; at 1200 it is 0.021167 mm. Higher DPI does not guarantee doubled mechanical accuracy or smaller burns. Distinct exposures can round onto the same coordinates and are retained.

Laser review embeds the actual optimized device-grid paths. Play/Pause, speed, timeline, static view, travel and thin/predicted-width views are inspection controls only. Runtime is approximate and process-specific. Travel-distance savings are not the same percentage savings in total print time. Initial playback position is assumed X0/Y0; it is not live feedback.

SVG/DXF engines remain in the source but desktop delivery controls are currently paused for direct printing.

Small details and recoverable previews

Filter tiny fragments starts enabled at 0.030 mm whole-path length. It filters complete short fragments, not short edges inside a long route. Already-covered details can be removed automatically; other omitted details remain marked red with Locate controls and a source-detail page. Their omission is not proven electrically harmless.

After generation, filter-only changes can refresh the laser review using cached isolation geometry and retain the router bytes. Width/lane/spacing or board changes require fresh planning. A failed module gets diagnostics while the other module's valid preview remains available. Resolve it or explicitly disable it before combined final output.

If a profile cutter does not fit an internal cutout, the dialog offers a smaller actual tool, deliberate omission of those particular cutouts, or laser-only continuation. Omitted cutouts stay marked red and remain physically uncut. Restore omitted internal cutouts reverses the choice. Outer-profile errors cannot simply be skipped.

Router settings and operation order

Assign nearby source drill sizes to the same actual tool in the drill-group table. Counts, original sizes and program count remain visible. Configure PCB thickness, breakthrough, actual profile diameter, feeds, pecks, approach, travel clearance, park height and spoilboard pin depth for the real setup. Slot machining is not implemented.

The tested tool-setting routine leaves Z at machine maximum. Each program first moves XY directly to its first actual hole/cutting start, then lowers Z there. Confirm that this matches the controller and physical setup. Initial motion from an unknown position is not fully simulated.

Spoilboard programs use Z0 on the spoilboard top. PCB drilling/profile use Z0 on PCB top; reset it for each tool. Retain the selected XY datum. Spindle speed is manual; M03/M05 start/stop remain automatic. There is one program per tool. Separation precedes the outside profile; current profiles have no holding tabs.

Router review includes copper context, actual parsed motions, current/all-tool playback, Previous/Next, setup notes and estimated motion timing. Animation does not model stock, unknown initial descent, manual changes or machine acceleration exactly. Workholding and actual tooling remain physical checks.

CNC Separation user layer

Use one user layer named CNC Separation for separation centerlines. Visible line thickness is only a design aid; the configured profile bit determines cut width. Crossing/touching/overlapping paths are accepted. Short lines retain intended bridges. Lines beyond the perimeter are clipped to board material, not extended. Separation runs before outside profiling with the same actual profile tool.

Main-view reference layers

Reference layers… opens the saved board's layer checklist. Layers start hidden and load on demand. Adjust opacity or Hide all. Silkscreen, mask, fabrication, courtyard, other copper and user layers use original, unmirrored source coordinates. Empty layers may have no ink. Fit board includes visible reference artwork.

References are main-view only: no manufacturing, review, paper-output or ready-preview changes. They survive generation and reset when another board is loaded. Older jobs without a verified board snapshot cannot supply extra layers; open the saved KiCad board for a fresh snapshot. Unsaved changes are never shown.

Print 1:1 and share reviews

Print 1:1 in a newly generated Laser/Router review opens a separate full-board paper view independent of zoom/playback. Choose copper, holes, outline and paths, current/all router paths, and optional labelled mirroring. Laser holes use source sizes; router holes use assigned tools and manual registration sizes.

Use 100% / Actual size, disable Fit to page and browser headers/footers, and choose paper/orientation large enough. The app does not shrink or tile the artwork. Measure the printed 50 mm horizontal and 20 mm vertical bars before judging component fit. Paper printing is not laser submission.

Save router ZIP… beside Router review saves its exact standalone HTML plus opening instructions, without machine files. Extract and open Router Review.html on the other device. It retains the original draft/released status and last generated settings; it does not reflect later unsaved edits. Animation and paper controls are embedded when present in that review.

Milestone limits

Current focus is Windows, single-sided B.Cu, Epilog Helix and a Laguna-specific MMG workflow. Double-sided jigs, via-rivet rules, accessory control, tool libraries, V-bit scoring, panelization, raster artwork and more general import handling remain roadmap work. A tested board and software checks do not guarantee another machine/material/process. Configure and inspect the actual setup.
