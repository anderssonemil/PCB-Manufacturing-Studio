# Changelog

## 0.3.0-rc.1 — single-sided manufacturing milestone

- Preserves the developed single-sided KiCad → laser/etch → CNC workflow.
- Direct Helix encoding/submission, actual-grid optimization and animated review.
- Adaptive directional isolation and corrected tapered-corner fallback handling.
- Grouped drilling, pecks, rapid approach, XY-first startup and separation before profile.
- Temporary-pin registration with pins removed after taping; circular outline candidates.
- Independent previews/diagnostics, fragment controls and explicit cutout decisions.
- Main-only reference layers, 1:1 paper checks and shareable router review ZIPs.
- Updated source documentation, credits, pinned helper build and self-contained portable app.

Earlier 0.1/0.2 portable builds were development prototypes, not this direct-print milestone.
