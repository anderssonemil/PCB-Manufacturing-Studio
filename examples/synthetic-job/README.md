# Synthetic offline demonstration

Generated 20 × 10 mm test geometry with a copper circle, four drill locations and
a rectangular outline. It is not a working circuit or a production machining job.
Open this folder with Open existing job to inspect the app without private designs.
Do not send its files to a laser or CNC. No KiCad snapshot is included, so extra
reference layers are intentionally unavailable. Original synthetic data is MIT.
