# Real board — standalone manufacturing reviews

These are the owner's shared review files for **Transducer Connectors to Logger Junction Box**, copied unchanged from the manufacturing output. They contain the board geometry and process settings intentionally shared as examples.

- [Laser review](Laser-Review.html) — direct Helix isolation paths, predicted burn footprint, travel and playback. Approximately 16.5 MB.
- [Router review](Router-Review.html) — drill/profile operations, setup details, copper overlay and toolpath animation. Approximately 0.4 MB.

## How to open

GitHub displays HTML as source rather than running the review. Open a file above, download its raw contents (Download raw file), then open the downloaded HTML in a modern browser with JavaScript enabled. Each HTML is independent: it needs no companion folders, server, internet connection, Python, or installed application. You can email either file as an attachment. Some email/cloud viewers disable JavaScript; download and open locally for the interactive controls.

The embedded HTML, CSS, JavaScript and geometry are self-contained. There are no external scripts, stylesheets, images, network requests, or local absolute-path references. Print controls open a browser print view generated from embedded data. Reviewing these files cannot send a job to either machine.

These are historical, board-specific examples, not generic machine programs or approval of another setup. Embedded feed rates, tool sizes and trial laser calibration describe this example only. No executable, PRN or CNC program is included in this example folder. Geometry and animation are illustrative reviews, not machine feedback or a full stock-removal simulation.
