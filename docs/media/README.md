UI screenshots and animated GIF were captured from the running PCB Isolator application, using the unchanged B.Cu layer of the 555 Timer Clock design by Franz Louis Vigilar (2026), MIT license. The full board is two-sided; these pictures demonstrate the current single-sided workflow, not a validated fabrication plan for that complete circuit.
