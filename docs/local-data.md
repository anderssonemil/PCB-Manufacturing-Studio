# What is deliberately local

The source repository does not include personal PCB designs, original macro photos,
calibration handoff bundles, transmission records, workbench device settings, runtime
binaries, Python environments, generated previews or CNC programs. Their original
locations are retained; preparation did not delete or relocate experimental evidence.

Before updating documentation/build files, a private preservation ZIP with per-file
SHA256 inventory was created outside the repository. It includes the original notes,
settings, boards and helper files. Rebuildable environments/caches and quarantine data
were excluded; they remain in their original locations. Do not upload that archive.

Public docs/history.md and docs/calibration.md are curated summaries. Historical
append-only notes remain locally ignored rather than being mistaken for current
instructions. Future maintainers should add reproducible synthetic cases rather than
copying an owner's boards or screenshots into Git by accident.
