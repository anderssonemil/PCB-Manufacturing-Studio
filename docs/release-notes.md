# 0.3.0-rc.1 — single-sided workflow baseline

Private review milestone before double-sided manufacturing and accessory-control work.
The Windows x64 portable ZIP includes Python, Qt, geometry libraries and the private
Java/LibLaserCut encoder. Extract completely and run PCB Isolator.exe. KiCad 8/9 is
still required separately for saved-board exports and uncached reference layers.

This preserves the owner's completed-board workflow, current laser/router reviews,
paper checks, reference-layer viewing and router ZIP sharing. Process settings and
controller assumptions remain hardware-specific; it is not universal CAM validation.
No autofocus, accessory automation, double-sided manufacturing or slot machining is
claimed. Existing user settings and job history remain outside the app install folder.

Source and runtime attribution are included. Private designs, original calibration
photos and historical workspace files are retained locally, not uploaded. This release
is unsigned. See the archive SHA256 and BUILD-MANIFEST.json for the exact build identity.
